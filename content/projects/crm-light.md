A lightweight, self-hosted CRM designed specifically for Shopify and Shopify Lite stores. Features a serverless Cloudflare Workers API backend, Neon serverless Postgres database, and an RTL-first React 19 dashboard. Includes automated bidirectional Shopify store synchronization, custom sales pipeline stages, and public storefront APIs.
